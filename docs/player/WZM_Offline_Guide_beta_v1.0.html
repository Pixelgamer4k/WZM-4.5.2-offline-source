1. Quick start (30 seconds)

  1. Open the game from its icon. Wait for the main menu (about 30–60 s). If it freezes on the Activision logo, wait — it restarts itself.
  2. About 20 s after the menu appears, a small orange WZ ball shows on the left. Everything is already unlocked.
  3. Tap the ball → choose Map, Mode, AI difficulty, Class, enemy/friendly bots → tap PLAY.
  4. You spawn with the chosen class; the bots join a few seconds later. Pause → Main Menu ends the match.

2. The floating ball

  • Tap the ball → opens the OPTIONS menu (it springs out of the ball). Drag it anywhere; it snaps to the screen edge.
  • After 10 seconds without use it fades to a faint ball (still visible) in the same place.
  • When it is faint: tap once to bring it back, then tap again to open the menu.
  • It also works during a match (e.g. to change graphics live).

4. PLAY, Gear Up and restarts — the one rule to remember

PLAY is instant only in a "fresh" game session. After you open GEAR UP or finish a match, the PLAY button turns amber and reads ↻ RESTART & PLAY: the game restarts itself (~1 minute) and your match starts automatically. Do not tap anything while it restarts.
  • Why: Gear Up's weapon list uses a game memory pool that a match also needs; and the game's protection closes a second match in the same session. A clean restart avoids both.
  • Gear Up (3D): use the game's own GEAR UP tile. In a fresh session the first tap loads the 3D menu: the status says "Loading 3D Gear Up", the menu refreshes once, and about 1 minute later Gear Up opens by itself with 3D operators and guns. Don't tap during that minute.
  • Gear Up after a match opens without 3D (the 3D menu only loads before the first match of a session).
  • Operator and skin: Gear Up → Operator → pick operator and skin → EQUIP. Your operator, skin, finishing move, taunt and intro are saved (every 30 s) and used in every match, also after restarts. Loadouts save the same way.
  • After a match: Pause → Main Menu → Yes returns to a working main menu with everything unlocked again.

7. If something goes wrong — Export Logs

  1. Tap the ball → Export Logs (bottom bar).
  2. Android's share menu opens with the log as text (device, app version, settings, agent log, game log). Nothing is saved on the phone.
  3. Send it to yourself (WhatsApp/Telegram/email/Drive) and pass it on for fixing. Do it right after the problem, before restarting the game.

8. Things to keep in mind

  • Never uninstall the game. Uninstalling deletes ~13 GB of game data in Android/data/com.activision.callofduty.warzone. Updates are always installed over the existing game.
  • Back up that data folder before experimenting or moving to another phone (restore into the same folder before first launch).
  • Your Gear Up loadouts and panel settings are stored inside the game's private storage on each phone — a new phone starts with defaults.
  • Don't tap during ↻ RESTART & PLAY or during a logo stall restart.
  • No internet or Activision account is needed to play. Leave Wi-Fi on only if you need wireless debugging.
  • Native resolution and Uncapped fps make the phone hotter; 640p / 60 fps is the tested, stable setup.
  • The version label (bottom-right of the menu, e.g. r19) tells which build you have — include it when reporting issues.
